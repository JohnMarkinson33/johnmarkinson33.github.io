finTB — Terms of Use

Last updated: July 2026

1. Nature of the application

finTB is a private, non-commercial personal finance application. It is developed, operated and used by a single person — its owner. It is not offered as a service to any other party.

2. Scope of use

The application reads the owner's own bank account information (read-only access: accounts, balances, transactions) through the Enable Banking API on the basis of the owner's explicit consent. The application does not initiate payments.

3. Data

Handling of data is described in the Privacy Policy. In short: single user, own data only, stored locally, shared with no one.

4. Liability

The application is provided "as is" for the owner's personal use, without warranty of any kind. As the sole user is also the operator, no consumer relationship arises.

5. Termination

The owner may stop using the application and revoke bank access consent at any time in internet banking or by disconnecting the session.
